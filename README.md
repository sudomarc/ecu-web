# ecu-web

This repository is the starting point for a web project and a governance-ready workspace for disciplined AI-assisted development.

The project intentionally includes a minimal Vibe Coding Instructions scaffold so future work can follow the same standards used by the upstream governance repository.

## Included structure

- `AGENTS.md` — project policy and operating loop
- `.ai/` — core governance, skills, contracts, templates, and agent catalog
- `.github/instructions/` — repo-local conventions
- `scripts/` — validation and utility scripts

## Default workflow

1. Read AGENTS.md and the relevant project-local instructions.
2. Inspect the minimal repo state before editing.
3. Keep the change small and aligned to user intent.
4. Verify with the narrowest useful check.
5. Review the final diff before completion.

## Relationship to upstream guidance

This repository is intentionally aligned with the policy structure described in:

- `https://github.com/sudomarc/vibe-coding-instructions`

The copy here is a lightweight scaffold, not a replacement for project-specific tech decisions.
