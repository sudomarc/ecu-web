# Ecosystem Mission Contracts

This directory defines portable contracts for agent roles and shared governance vocabulary.

## Standard permissions

- READ_ONLY
- WORKSPACE_WRITE
- ISOLATED_EXECUTE
- NETWORK_ACCESS
- PRIVILEGED_MUTATION

## Standard stop conditions

- SUCCESS_VERIFIED
- MAX_BUDGET_REACHED
- GOAL_BLOCKED
- SAFETY_TRIGGERED
- HUMAN_CHECKPOINT_REQUIRED

## Evidence labels

- FACT
- OBSERVED
- VERIFIED
- INFERENCE
- ASSUMPTION
- UNKNOWN
- CONFLICT
- UNVERIFIED
