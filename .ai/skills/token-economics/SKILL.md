# Token economics

This skill keeps retrieval, tool usage, reasoning, and delegation efficient.

## Cost discipline

- Retrieve only the minimal necessary context.
- Prefer targeted search, line ranges, and narrow reads.
- Combine compatible tool calls when possible.
- Avoid rereading unchanged evidence.
- Keep outputs concise but complete.

## Decision standard

Before a costly tool or model step, define the decision it will support and the smallest useful scope.
