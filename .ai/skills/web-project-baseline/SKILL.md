# Web project baseline

Treat this as the baseline working framework for a new web project or a launch-readiness pass.

## Goals

- define a minimal production-safe shell,
- inventory routes and primary user flows,
- identify the source of truth for content and data,
- define form lifecycle and validation behavior,
- inventory browser storage and consent requirements,
- verify that the app can run without hidden assumptions.

## Guardrails

- Prefer small, explicit implementation over broad rework.
- Verify runtime behavior before claiming launch readiness.
- Treat compliance and consent requirements as evidence-driven, not default assumptions.
