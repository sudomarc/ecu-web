# AI governance scaffold

This directory contains the minimal, portable governance layer for this repository.

## Layout

- `core/` — shared repository policy and conventions
- `agents/` — provider-neutral agent catalog
- `contracts/` — role contracts and safety vocabulary
- `skills/` — task-specific operational guidance
- `templates/` — reusable planning and reporting formats

## Principles

- Load only the relevant subset for the task.
- Prefer targeted reads over broad repository-wide dumps.
- Keep evidence explicit and verification-driven.
- Keep changes scoped, local, and reviewable.
